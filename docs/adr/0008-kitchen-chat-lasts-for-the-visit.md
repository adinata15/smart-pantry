# Kitchen chat lasts for the visit

A kitchen chat is the conversation on the open chat page. Each reply gets a chat context: the member's display name and the kitchen facts for that reply (stock, expiry, favorites, catalog recipes, and shopping needs). The context is not stored. Leaving the page drops the turns, so the next visit starts empty. Email and passwords stay out of the prompt.

A saved thread would keep questions the member did not ask to store. An End chat button would leave the thread in place until they remembered to tap it.
